### 3. 数据众包机制：共享采购联系人赚取 Credit (UGC Data Flywheel)

为鼓励外贸销售人员盘活存量客户资源并丰富平台底层 CRM 库，建立“数据互换”机制：
* **基础兑换率**：用户提交 1 位真实有效的海外企业采购决策人邮箱并通过系统校验 ➡️ **奖励 +10 Credits**（直接等价于免费兑换 1 篇深度研报阅读，或换取 2 位其他买手联系方式）。
* **防作弊与风控规则**：
  1. **企业域名限制**：仅限企业企业域名邮箱（自动拦截 `@gmail.com`, `@qq.com`, `@163.com`, `@foxmail.com` 等公共免费邮箱）。
  2. **SMTP 自动化握手核验**：调用项目已有的 `/api/contacts/verify-single` 服务进行在线可达性探测，验证真实有效后即时发放奖励。
  3. **唯一性去重**：库内已收录的相同邮箱不重复发放奖励。
  4. **月度上限保护**：Free 用户每月通过众包最多获取 500 Credits，防止脚本批量刷取。

### 4. 点数余额与扣减优先级逻辑 (Credit Engine)

* **数据库字段设计**：
  * `subscription_credits` INT DEFAULT 0：订阅周期点数（月付/年付每月自动充能，当月周期结束时重置刷新）。
  * `permanent_credits` INT DEFAULT 100：永久点数（注册赠送、按需点数包购买、UGC 联系人众包奖励、邀请好友奖励，永不过期）。
  * `member_tier` VARCHAR DEFAULT 'free'：`'free'` | `'pro_monthly'` | `'pro_annual'` | `'enterprise'`。
  * `pro_subscribed_at` TIMESTAMP WITH TIME ZONE：订阅起始时间。
  * `pro_cycle_expires_at` TIMESTAMP WITH TIME ZONE：当前 30 天月度周期的截止时间。
* **消费扣减顺序**：
  $$\text{先扣除即将过期的 } subscription\_credits \longrightarrow \text{不足时扣除永久点数 } permanent\_credits$$

## 三、 ⚖️ 架构与技术决策记录 (ADR)

### ADR-001: 个人免执照微信/支付宝收款方案选型
* **背景**：项目需为 Pro 会员（月付/年付）与按需点数包开通微信和支付宝扫码收款能力，但目前无企业/个体工商户对公资质。
* **备选方案调研**：
  1. *方案 A（普通易支付平台，如 fqzf.cc）*：开户费低（¥5），但资金沉淀在第三方平台资金池，需手动提现，存在平台跑路或查封风险。
  2. *方案 B（正规小微直连，如 蓝兔支付 ltzf.cn / 虎皮椒 xunhupay）*：开户费约 ¥50~100，个人身份证即可签约微信/支付宝小微商户，**资金直接由微信/支付宝官方清算到个人银行卡/微信零钱，零资金滞留风险**，综合费率约 1.3%。
* **最终决策**：
  * **首选推荐**：蓝兔支付（`ltzf.cn`）或 虎皮椒（直连结算、安全合规）。
  * **架构兼容性设计**：后端编写标准的统一支付驱动适配层（`PaymentDriver`），后续切换支付通道或升级为企业微信支付仅需变更 `.env` 配置，订单处理与会员升级业务逻辑零修改。
