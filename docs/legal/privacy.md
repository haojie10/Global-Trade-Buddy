# 外贸智友 (Globaltradebuddy) 用户隐私政策

**最近更新日期：2026年7月4日**

**版本生效日期：2026年7月4日**

外贸智友 (Globaltradebuddy)（以下简称“我们”或“本平台”）深知个人信息及商业秘密对您的重要性。我们致力于保护使用本平台服务的用户（以下简称“您”或“用户”）的个人信息及数据安全。

本隐私政策旨在向您说明我们在您使用外贸智友平台服务期间，如何收集、使用、存储、共享和保护您的个人信息，以及您管理个人信息的方式。**请在使用我们的服务前，仔细阅读并充分理解本政策，特别是以加粗或下划线标识的条款。**

---

## 1. 我们如何收集您的信息

为了向您提供核心服务及保障账户安全，我们会收集您在注册、登录及使用服务过程中主动提供或产生的以下信息：

### 1.1 账户注册与登录
*   当您注册或登录外贸智友时，您需要提供您的**手机号码**或**电子邮箱地址**，以创建您的平台账户。
*   如果您使用邀请码注册，我们会记录您与邀请人之间的关联关系，以便计算和发放邀请裂变额度。

### 1.2 资讯服务与个人拓扑图谱
*   **解锁与阅读记录**：我们会记录您所解锁的报告（包括客户 360 度画像和品类洞察报告）的 ID 及解锁时间，以生成您的**个人已解锁报告列表**，并为您扣除相应的免费或付费额度。
*   **个人笔记挂载**：如果您在解锁报告下添加个人笔记，我们将收集并存储您**输入的笔记文本内容**，并在您的私人星空图谱中将其挂载为节点。**您的个人笔记属于高度机密信息，仅您个人账户可见，我们绝不会将其共享给任何第三方。**
*   **报告收藏夹**：我们会记录您收藏的报告，方便您快速检索。

### 1.3 安全防护与系统日志
*   为识别账号异常状态、防止恶意刷量（如邀请裂变作弊）、保障系统稳定运行，我们会收集您的**设备信息**（如浏览器类型、操作系统、IP 地址）和**网络日志信息**（包括访问时间、页面停留时间、操作行为）。

## 2. 我们如何存储您的信息

### 2.1 存储地点与数据合规性
*   **本地化存储**：我们在国内主流云厂商服务器上部署了开源 Supabase 数据库堆栈。**您所有的个人信息、解锁记录、交易报告数据和个人笔记均保存在中国境内的服务器上，不涉及任何跨国数据出境。**这符合中华人民共和国《个人信息保护法》及相关法律法规的合规要求，最大限度降低数据泄露及监管风险。

### 2.2 存储期限
*   我们仅在为您提供服务所必需的期限内，或在法律法规要求的时限内保留您的个人信息。
*   当您注销账户或我们停止运营本平台时，我们将依据法律法规要求，对您的个人信息进行删除或匿名化处理。

---

## 3. 我们如何使用您的信息

我们收集的信息将用于以下用途，如果我们要将您的信息用于本政策未载明的其他用途，会事先征求您的同意：
1.  **向您提供基本服务**：包括展示资讯大厅、实现报告解锁、以及生成个人网状拓扑图谱。
2.  **安全核验与防护**：分析用户网络日志，防止恶意注册、爬虫批量拖库或邀请裂变欺诈。
3.  **防盗水印生成**：我们会利用您的手机号或用户 ID 在已解锁的报告底层生成**动态数字水印**，并在图片和图表中嵌入**隐形盲水印**，用于报告防盗与外泄后的来源追溯。
4.  **服务改进与推送**：根据您的品类阅读偏好，在平台内为您推荐可能感兴趣的最新外贸洞察报告。

---

## 4. 我们如何共享、转让或公开披露您的信息

*   **共享与转让**：我们不会向任何第三方公司、组织或个人共享或转让您的个人信息，除非获得您的明确同意，或为遵守法律法规、法院判决、政府部门强制要求所必需。
*   **公开披露**：我们绝不会公开披露您的个人信息，除非基于法律法规、法律程序或政府主管部门的强制性要求。
*   **第三方 SDK 或插件**：我们可能会接入第三方服务（例如系统运行监控、页面分析、客服支持服务等）。我们在接入时会进行严格的安全评估，确保其数据收集和使用行为符合本政策的隐私保护标准。

## 5. 您的权利

我们非常重视对您个人信息的管理，并为您提供了以下管理权利：
1.  **查询与更正**：您有权通过平台个人中心查询您的账号绑定信息、已解锁报告列表、收藏夹以及剩余解锁额度。
2.  **删除个人笔记**：您可随时删除您在报告下添加的个人笔记，删除后该笔记节点将立即从您的星空知识网络中移除，且在数据库中永久擦除。
3.  **注销账户**：您可以通过平台内的联系方式申请注销您的账户。在账户注销申请核验通过后，我们将停止为您提供服务，并依法删除或匿名化处理您的个人信息。
4.  **撤回同意**：您可以通过修改个人隐私设置或关闭相关权限来撤回您对我们收集特定个人信息的同意。

## 6. 信息安全保障与防盗泄机制

*   我们采用行业标准的加密技术（如 HTTPS 传输加密、密码 Hash 加密等）以及物理服务器访问控制，保护您的数据安全。
*   **水印追踪声明**：请您务必知悉，您解锁的所有报告页面均包含**显性动态水印**（包含您的注册手机号/电子邮箱及时间戳）及**隐形盲水印**。一旦发现报告内容被私自截图、拍照或导出并传播至非平台环境，我们将通过水印技术定位泄漏源头账户，并依法追究该账户持有人的法律责任。
