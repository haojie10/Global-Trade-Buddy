# 导航栏与报告卡片 UI 升级设计规格说明书 (2026-06-29)

本规格说明书定义了所有页面（首页与图谱页）导航栏的配色升级、报告列表卡片的视觉对比度与鼠标悬停动效增强，以及报告解锁状态动作文字渲染的重构，以进一步提升产品视觉层次与用户体验。

## 1. 导航栏 Header 配色升级

### 1.1 背景颜色与布局
- 将所有导航栏（目前包括首页 `pages/index.tsx` 和图谱页 `pages/my-graph.tsx`）的 `background` 改为系统品牌色 `#ff641e`。
- 去除模糊背景叠底，采用高饱和度的纯白阴影 `box-shadow: 0 10px 30px rgba(255, 100, 30, 0.15)`，让导航栏拥有漂浮与聚焦效果。

### 1.2 字体与按钮色彩对齐 (Web Accessibility)
为了在强橙色底色上保持良好对比度，导航栏内的文字和图标一律转为纯白或微透明白：
- **文字与图标**：Logo 文字、指示图标、额度说明（如“游客模式”、“普通用户”、“剩余额度：x 次”等）全部渲染为 `#ffffff`。
- **按钮样式（磨砂半透明白）**：
  - 导航栏中的所有普通按钮（如“返回平台报告大厅”、“登录/注册”、“退出登录”）取消原本的浅沙色底图，改为磨砂质感的半透明白色背景：`background: rgba(255, 255, 255, 0.15)`，配以极细描边 `border: 1px solid rgba(255, 255, 255, 0.25)`，文字渲染为 `#ffffff`。
  - Hover 悬停态：背景变亮 `background: rgba(255, 255, 255, 0.25)`，提供良好的交互反馈。

---

## 2. 报告卡片 (Report Card) 视觉与悬停动效升级

### 2.1 卡片底色加深 (增强对比度)
- 现有的报告卡片背景与页面背景色过于接近，对比度较弱。
- 将卡片在未悬停时的默认背景颜色改为带有暖木茶沙色质感的稍深底色 `#efe9df`。该颜色与网页暖乳白底色对比鲜明，使卡片轮廓非常突出。

### 2.2 鼠标悬停变品牌色及子元素全白
- 采用纯 CSS 声明来处理悬停渲染，保证交互流程的高刷新率：
  - 悬停时，卡片背景过渡到品牌色 `var(--color-accent, #ff641e)`。
  - 卡片内所有的文本子节点、分类 Tag、地区图标及描述文字，一律通过 CSS 强制转换颜色为 `#ffffff`。
  - 未解锁状态按钮在悬停时转换为半透明白 `rgba(255, 255, 255, 0.2)` 背景，已解锁标签也进行相应配色漂白。

---

## 3. 报告解锁状态展示逻辑重构

根据用户的解锁状态，卡片右侧的引导动作仅显示对应的一种：
- **已解锁状态**：
  - 左侧显示绿色“已解锁”标签。
  - 右侧文本更改为“立即阅读 →”以示区分。
- **未解锁状态**：
  - 左侧显示橙黄色“未解锁”密码锁按钮。
  - 右侧文本维持“立即预览与解锁 →”。
- 二者逻辑隔离，卡片上绝不同时并存状态矛盾的提示信息。
