# 行业新闻与热点情报 (report-news)

本技能用于自动跟踪全球外贸热点（关税调整、运价波动、海外买家动态、法规升级），并将其转化为包含“外贸影响分析”的精简新闻情报。

## 核心工作流

1. **热点信息搜集**：使用 `search_web` 搜集最新的外贸资讯（如“北美关税”、“海运费”、“欧代/法案升级”）。
2. **结构化情报提炼**：
   - **标题**：痛点高唤醒标题（例如：《欧盟禁伐令 EUDR 延期？对华木制品/家具出口工厂的影响》）
   - **事件概述**：100 字清晰阐述事实。
   - **外贸链条影响分析**：分析对中国出口工厂、外贸 SOHO 和海外买家的直接冲击。
   - **应对策略**：2-3 条落地的建议。
3. **输出与保存**：
   - 生成 Markdown / HTML 情报，存入 `d:/我的APP/Globaltradebuddy/content-pipeline/news/[日期-热点标题.md]`。
4. **同步上传平台**：发布至 GlobalTradeBuddy 的 News 资讯板块。
