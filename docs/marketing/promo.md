# 外贸智友 (Globaltradebuddy) — 您的全智能出海展业与客情分析伴侣

在当今瞬息万变的全球贸易环境中，外贸从业人员面临着前所未有的挑战：客户采购动机难捉摸、供应链背景不透明、买家违约风险增加、产品在目标市场的准入条件和税率变动频繁，以及琐碎的客户情报难以系统化整理。

**外贸智友 (Globaltradebuddy)** 是一款专为中国外贸业务员、外贸 SOHO 及出海企业高管量身打造的**高端资讯分析与私人客情图谱平台**。通过前沿的 AI 数据处理技术和独创的网状拓扑图谱，帮助您深挖供应链隐秘线索，洞察市场商机，规避交易风险。

---

## 一、 核心价值主张：四大产品支柱

### 1. 客户 360 度深度画像 — 知己知彼，百战不殆
摆脱单一的海关数据查询，外贸智友为您提供全方位的海外买家“体检报告”：
*   **供应链背景穿透**：洞察买家的核心供应商网络、历史采购频次与品类偏好。
*   **财务与信用评估**：分析买家的信用评级、潜在的违约风险与财务健康状况，从源头过滤不良客户。
*   **采购特征解析**：判断买家是倾向于“高频小额”还是“低频大宗”，帮助您精准定制报价策略。

### 2. 品类与渠道洞察报告 — 把握趋势，精准出海
针对海外主要市场（如北美、欧洲、东南亚）和主力零售渠道（如 Home Depot、Lowe's、Dollarama 等）进行深度品类调研：
*   **市场渗透率分析**：直观展示特定品类（如汽配、五金、园艺工具）在目标区域的销售占比与增长红利。
*   **渠道准入与上架逻辑**：解密海外头部零售商的供应商选择标准、包装要求及绿色环保准入条件。
*   **制造端升级建议**：基于目标市场的消费者反馈与法规趋势（如锂电化、轻量化），指导工厂研发升级。

### 3. Obsidian 式星空知识图谱 — 顺藤摸瓜，发现隐藏商机
外贸智友独创“千人千面”的网状拓扑图谱，将您解锁的所有客户报告、品类报告和个人笔记以可视化星空网络的形式呈现：
*   **实体关联网络**：自动提取报告中的“买家”、“供应商”、“主营产品”、“销售渠道”等实体，通过线条将其串联。
*   **顺藤摸瓜式探索**：点击图谱中的任意节点，即可快速查看该实体的详细背景；页面下方提供高频关联推荐，帮助您沿着商机链条无限延伸。
*   **商机穿透**：例如，您可以清晰地看到“客户 A”与您竞争对手的共同供应商，或是“渠道 B”与您所卖品类的潜在联系，在网络中直接锁定未被开发的蓝海买家。

### 4. 外贸精英提效工具箱 — 展业工具，一应俱全
集成多项日常外贸高频使用的提效辅助工具，无需在多个网页间切换：
*   **AI 商品图智能美化**：工厂拍摄的样品原图太杂乱？一键智能抠图，自动调整光影，替换为极简白底图或高级 3D 展厅背景，让产品图瞬间具备国际大牌感。
*   **实时汇率计算与走势**：提供全球主流外贸结算币种的实时结汇汇率换算，辅以波动趋势图表，帮您把握结汇黄金时机。
*   **HS Code 智能查询**：输入产品名称快速匹配海关编码，同步查询出口退税率、海关监管条件与目标国进口关税。
*   **时区黄金发送看板**：结合客户所在国的作息时间与邮件打开率大数据，智能推荐开发信与即时消息的“黄金发送时间窗”，大幅提升回复率。

## 二、 拓展功能与生态裂变

*   **个人笔记挂载**：支持在任意已解锁的报告或实体节点下添加您的专属跟进记录、谈判纪要或客情分析。个人笔记将作为专属私有节点融入您的知识网络，构建您的私人出海“第二大脑”。
*   **报告收藏夹**：一键将高价值的研究报告和关键实体加入收藏，随时随地快速检索。
*   **邀请裂变机制**：通过专属邀请码或邀请链接推荐同行注册。每成功邀请一位新用户，您与被邀请人均可获得额外的免费报告解锁额度，实现互利共赢。

## 三、 严苛的安全性与合规保障

对于外贸企业而言，客情数据和采购线索是核心机密。外贸智友在技术底层实施了多重保护，确保您的数据资产万无一失：
1.  **数据安全与隐私合规**：采用 Docker 本地化部署开源 Supabase 数据库，所有用户数据、解锁记录和个人笔记均严格存储在国内云服务器中。完美规避《个人信息保护法》中的“数据出境”合规风险。
2.  **动态防盗水印**：在已解锁报告的展示页面底层，动态铺设包含您手机号与时间戳的 Canvas 数字水印。
3.  **隐形盲水印追踪**：生成肉眼不可见的隐形盲水印嵌入网页与图表中，一旦发生报告截图、拍照外流，可精准追溯泄漏源头，强力保护商业机密不被非法扩散。
4.  **接口级安全拦截**：所有报告全文的读取请求均通过后端数据库的 `unlocks` 权限校验，未解锁用户绝对无法越权获取数据包，防范网络爬虫批量抓取。
